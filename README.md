# Apresentação - CRUD de Amigos

Apresentação do projeto desenvolvido na disciplina de **Programação Web II**, abordando o sistema de cadastro de amigos (CRUD) e o sistema de login.

## Conteúdo

A apresentação aborda:

* Sistema de login;
* Cadastro de amigos;
* Listagem dos registros;
* Atualização dos registros;
* Exclusão dos registros;
* Conexão com o banco de dados;
* Controle de acesso por sessão;
* Estrutura dos arquivos PHP;

## Arquivo da apresentação

A apresentação está disponível neste repositório em formato ODP:

**`apresentacao_crud_amigos.odp`**

## Tecnologias utilizadas

* PHP
* MySQL
* MySQLi
* HTML
* W3.CSS
* Session
* XAMPP

## Disciplina

**Programação Web II**
